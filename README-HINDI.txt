VISHAL BIRTHDAY WEBSITE — हिंदी में शुरू करने के स्टेप्स

इस ZIP में:
- index.html — पूरी responsive birthday website
- photos/ — आपकी 6 तस्वीरें
- कोई build command या paid service जरूरी नहीं है।

नाम बदलना:
1. index.html खोलें।
2. नीचे JavaScript में const SENDER = "Vishal"; मिलेगा।
3. चाहें तो "Vishal" को दूसरे नाम से बदलें। अभी wish भेजने वाले का नाम Vishal रखा है।
4. Birthday पाने वाले का नाम बताने पर मैं उसे भी वेबसाइट में जोड़ सकता हूँ।

GitHub Pages पर FREE लाइव करने का तरीका (मोबाइल):
1. github.com खोलें और लॉगिन करें।
2. + दबाएँ → New repository.
3. Repository name: vishal-birthday-website रखें और Public चुनें।
4. Create repository दबाएँ।
5. Add file → Upload files चुनें।
6. ZIP को पहले मोबाइल में Extract करें। फिर index.html और photos फोल्डर के अंदर की 6 तस्वीरें अपलोड करें। ZIP को अकेले अपलोड करने से वेबसाइट नहीं चलेगी।
7. Commit changes दबाएँ।
8. Repository में Settings → Pages खोलें।
9. Build and deployment में Deploy from a branch चुनें; Branch: main और folder: / (root) चुनकर Save करें।
10. 1–5 मिनट बाद Pages पेज पर दिया गया लाइव URL खोलें।

ध्यान दें:
- index.html और photos फोल्डर एक ही root जगह पर होने चाहिए।
- फोटो आपकी भेजी हुई तस्वीरों से बनाई गई हैं।
- यह एक static birthday wish site है; इसमें login, database या visitor tracking नहीं है।
